    User guide — how to use this tool

    What this tool does

    Compares the client's internal trial balance against the working trial balance for the same period, matches the accounts between the two (exact, fuzzy, then AI for accounts named completely differently), quantifies every difference, and drafts the adjusting journal entry — exported as a three-sheet, client-approval-ready Excel workbook with live formulas.

    Inputs needed

    • The client's internal trial balance (e.g. a QuickBooks debit/credit export) and the audit working trial balance for the same period.
    • Upload as CSV or XLSX, or paste the data directly. Old .xls files are rejected — re-save them as .xlsx first.

    Steps

    1. New here? Click Fill with example data to run the whole flow on a fictional demo pair.
    2. Upload (or paste) both files — client name and period auto-fill from the filenames; edit them if needed.
    3. Pick the audit balance column to compare against (e.g. the report-date column).
    4. Click Run Reconciliation. Accounts are matched in three passes: exact/normalized names, fuzzy similarity, then an AI pass for accounts named completely differently — AI-matched pairs show a confidence you can review.
    5. Review the previews: the drafted Adjusting Journal Entry, the Summary, and the TB Comparison with differences highlighted. Notes explain one-sided items ("Not in client records" / "Not on audit working trial balance").
    6. Set the workbook file name and click Download Excel workbook.

    The workbook

    Three sheets, matching the real deliverable: the AJE with debit/credit lines under the client's own account names, SUM totals, and a balance check; the TB Comparison with live difference formulas and material differences highlighted; and a Summary with totals and a plain-English conclusion. What you preview is exactly what downloads.

    Notes

    • Works without an AI key — matching degrades gracefully to exact and fuzzy passes.
    • Nothing you upload is stored; every response is marked not to be cached.
